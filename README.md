42岁男性居家训练

## v1.2

原生 HTML/CSS/JavaScript 的居家训练打卡 PWA，保留现有训练计划、声音指导、训练历史和离线使用能力。

- 应用显示版本：1.2（index.html 的版本标签）。
- Service Worker 缓存版本：training-checkin-v12；沿用原有自动更新机制。
- 启动路径仍为 ./index.html；训练数据继续使用 jointSafeTrainingPwaV1，不迁移或重置。

### 本地记录

首页版本标签3秒内点击7次进入“训练数据校验”。首次使用需自行设置并确认6位校验数字，设置时输入遮挡；以后校验输入明文显示，保留数字键盘。

正确6位数字进入记录页；其他6位数字统一提示日期格式错误；有效8位公历日期仅模拟检测，不改动训练数据。

记录支持新增、编辑、自动保存和复制。点击编号，确认后删除。返回、页面隐藏、后台切换和刷新后锁定，再次进入需重新校验。

记录使用独立 IndexedDB，采用 PBKDF2-SHA-256（600,000次、随机 salt）派生不可导出密钥，使用 AES-256-GCM 和每次独立随机 IV 加密。没有默认凭据、普通重设入口、上传或遥测。

这是防止家庭成员偶然进入的轻量隐私保护，不是高安全级别的密码保险库。6位数字不能保证抵抗离线暴力破解。清除网站数据、删除 PWA 或浏览器清理存储有数据丢失风险；忘记校验数字无法正常恢复。复制后的系统剪贴板仍可能保留明文。第一版没有备份或云同步，后续建议增加加密备份导出/导入。实际使用需 HTTPS（本机开发可使用 localhost）。

### 开发与验证

本应用没有构建步骤，也不需要安装运行依赖。可用任意本地静态服务器预览。

自动检查脚本：

```sh
node tests/local-records.test.cjs
```

使用开发环境中已有的 Playwright 和浏览器；脚本不会自动下载浏览器。若 Playwright 位于其他工具的依赖目录，可通过 NODE_PATH 指向已有 node_modules。可以用 WEBKIT_EXECUTABLE 指定已有 WebKit 可执行文件。

测试使用独立浏览器上下文及运行时随机生成的校验数字，不读取用户日常浏览器数据。历史基线从保留的 Git 提交读取，生成的截图写入被忽略的 output/，无须提交本地备份或测试产物。

测试覆盖原有23组检查，并验证1.2版本显示、全新安装、旧训练版本缓存升级，以及已有加密记录从v11缓存升级后保留。桌面 WebKit 和事件模拟不能代替 iPhone Safari/主屏幕 PWA 的真实锁屏、后台快照与复制验收。
